# Vacíos prioritarios y preguntas operativas
Prioridad indica orden de investigación, no riesgo cuantificado ni fechas de entrega inventadas.

|---|---|---|---|

Para cada servicio confirmar: propio, externo dentro delhospital, referido fuera, o no ofertado; quién acepta solicitud yfirma acto, dónde queda fuente, cómo se confirma entrega/resultado/costo, quién responde ante caída. No asumir que todas las modalidades son legalmente admisibles para cada clase.
No se requiere enviar datos identificables depacientes, credenciales o diagnósticos depersonal para documentar políticas. Datos de ejemplo técnicos no son observación institucional.

## Paquete de levantamiento concreto
Permisos/actas/aprobaciones vigentes; organigrama yfunciones; catálogo/precios/contratos; formatos/SOP con versión; equipos/modelos/firmware/licencias/exportación; muestras desidentificadas de eventos/documentos; estadística definida con denominadores; registros de incidencias/reconciliación con accesorevisado.
Seleccionar casos ordinarios yexcepcionales de cada circuito. Documentar pasos, entradas/salidas, esperas, errores, relevo ydevolución real. Aprobar mapa con dueño antes de especificar cambios. No atribuir incidente observado aCLIMESA sin evidencia directa.
